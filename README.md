# 기사 프로젝트 노트

기사 한 건의 프로젝트 한 줄, 주제, 할 일, 날짜별 기록을 한 페이지에 적어 두는 HTML 노트입니다. 서버나 설치 없이 `article-project-note.html` 파일 하나로 동작하고, 휴대폰 화면에서도 읽기 편하게 만들었습니다.

## 구성

- **프로젝트 한 줄**: 기사 프로젝트를 한 줄로 적는 칸
- **주제**: 대주제(기본값 "AI와 교육")
- **할 일 체크리스트**: 기본 5칸, 항목 추가·삭제 가능, 진행률 표시
- **날짜별 기록**: 2026-11-18부터 날짜별로 한 줄씩 기록, 날짜순 자동 정렬

전화번호나 주소 같은 개인정보 칸은 없습니다.

## 사용법

1. 저장소를 내려받거나 `article-project-note.html` 파일만 저장합니다.
2. 파일을 브라우저(Chrome, Safari 등)로 엽니다.
3. 칸에 바로 입력하면 자동으로 저장됩니다.

휴대폰에서 쓰려면 파일을 휴대폰 브라우저로 열거나, 아래 GitHub Pages로 배포해 주소로 접속하면 됩니다.

### GitHub Pages로 배포하기

1. 저장소 **Settings → Pages**로 이동합니다.
2. **Source**를 `Deploy from a branch`로 두고, 브랜치와 폴더를 선택해 저장합니다.
3. 파일 이름을 `index.html`로 바꾸면 발급된 주소로 바로 열립니다. 이름을 그대로 두면 주소 끝에 `/article-project-note.html`을 붙여 접속합니다.

## 저장과 백업

입력한 내용은 사용 중인 브라우저의 `localStorage`에 저장됩니다. 서버로 전송되지 않고, 기기와 브라우저마다 따로 저장됩니다. 파일 위치나 접속 주소가 바뀌면 이전 내용이 보이지 않을 수 있고, 브라우저 데이터를 지우면 내용이 사라집니다.

- **텍스트로 복사**: 프로젝트, 주제, 할 일, 기록을 글로 만들어 클립보드에 복사합니다.
- **인쇄·PDF 저장**: 버튼과 삭제 표시를 뺀 화면으로 인쇄하거나 PDF로 저장합니다.
- **백업 파일 저장 / 불러오기**: 전체 내용을 JSON 파일로 저장하고 다시 불러옵니다. 기기를 옮기기 전에 사용하세요.

## 직접 고치기

스크립트 상단의 값을 바꾸면 됩니다.

| 항목 | 위치 | 설명 |
| --- | --- | --- |
| 기록 시작일 | `START` 상수, 날짜 입력의 `min` 속성 | 기본값 `2026-11-18` |
| 주제 | `<span class="tag">AI와 교육</span>` | 대주제 이름 |
| 색상 | `:root`의 CSS 변수 | `--accent`가 포인트색 |

`localStorage` 키는 `article-project-note-v2`입니다. 같은 주소에서 노트를 여러 개 쓰려면 파일마다 키를 다르게 지정하세요.

## 파일

```
article-project-note.html   노트 페이지 (HTML·CSS·JavaScript 포함)
README.md                   이 문서
```

외부 라이브러리와 외부 글꼴을 쓰지 않습니다. 글꼴은 기기에 설치된 것을 사용합니다.
